⏰ Gramática en contexto

Pasado pisado = pretérito indefinido (simple past)

We use the pretérito indefinido to talk about finished actions that happened at a specific moment in the past. The action started and ended — it's done, "stepped on" 👣. That's why we call it pasado pisado.

⭐ GOLDEN RULE ⭐
If I ask you ¿CUÁNDO? and you can tell me pretty exactly… that is pasado pisado! ⏰

¿Cuándo? These time expressions are your best friends:

ayeranocheesta mañanael lunes pasadola semana pasadael año pasadohace dos díasen 2019en diciembreel último día

Example: El fin de semana pasado visité Madrid. → ¿Cuándo? The last weekend. ✅ Pasado pisado!

🧩 3 types of verbs

1. REGULARES · VIAJAR ✈️Remove -ar and add the ending
yoviajé
túviajaste
él / ella / ustedviajó
nosotros / nosotrasviajamos
ellos / ellas / ustedesviajaron
👉 -ER / -IR verbs: -í, -iste, -ió, -imos, -ieron (comí, salió, vivieron). ⚠️ Don't forget the accent: viajé, viajó.
2. IRREGULARES · IR 🚌Totally new forms — learn them by heart
yofui
túfuiste
él / ella / ustedfue
nosotros / nosotrasfuimos
ellos / ellas / ustedesfueron
👉 SER has the same forms (context tells you the meaning). Other irregulars: hacer → hice, hizo; dar → di; ver → vi. No accents!
3. VERBOS UVE · ESTAR 🏨The stem changes to -UV- + special endings
yoestuve
túestuviste
él / ella / ustedestuvo
nosotros / nosotrasestuvimos
ellos / ellas / ustedesestuvieron
👉 Same pattern: tener → tuve; andar → anduve. Endings: -e, -iste, -o, -imos, -ieron (no accents).
💡 Tip: For negatives, put no before the verb: No compré nada. For questions, just use question marks and intonation: ¿Compraste algo?
